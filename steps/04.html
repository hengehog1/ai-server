4. Установка Claude Code

А вот и мозги нашей операции! Только не забудь: даже умному ИИ нужны понятные задачи! 🧠

Зачем это нужно

Claude Code — это ИИ-инструмент, который умеет работать с кодом, файлами и проектами. Мы установим его официальным способом, подключим через доступный способ авторизации и проверим на простом задании. Для использования потребуется подходящая подписка или оплачиваемый API-доступ.

Что нужно заранее

  • Ubuntu 20.04 и новее, минимум 4 ГБ ОЗУ и доступ в интернет (это требования из официальной документации).
  • Аккаунт Claude с доступом к Claude Code: подписка Pro, Max и выше, Team или Console с API-оплатой. Бесплатного тарифа для Claude Code недостаточно.
  • Страна из списка поддерживаемых.
Оплачивай подписку только официальными способами, доступными в твоей стране. Подробные инструкции и ответы на вопросы — в нашем Telegram-сообществе.

1. Установка

Подключись к серверу под пользователем ai (не root и без sudo) и выполни официальную команду установки:

curl -fsSL https://claude.ai/install.sh | bash

Установщик не показывает прогресс — это нормально. Когда он закончится, закрой терминал и подключись заново, чтобы система увидела новую программу.

2. Проверка

claude --version
claude doctor

Должно получиться: первая команда печатает номер версии, вторая сообщает, что установка в порядке. Если пишет «command not found», подключись к серверу заново или посмотри раздел про PATH в официальной документации.

3. Вход в аккаунт

Создай папку для первых экспериментов и запусти Claude Code в ней:

mkdir -p ~/workspace && cd ~/workspace && claude

Claude Code покажет ссылку для входа. Открой её в браузере на компьютере или телефоне, войди в свой аккаунт и вставь полученный код в терминал.

4. Первый запрос

Напиши прямо в Claude Code что-нибудь простое:

Создай файл hello.txt с приветствием и покажи, что в нём

Claude Code попросит разрешение на создание файла. Прочитай, что он собирается сделать, и разреши. Выйти из программы: /exit или два раза Ctrl+C.

Работай в отдельной папке (~/workspace), а не в корне сервера, и не давай разрешений «на всё» без необходимости. Claude Code обновляется сам в фоне.

Что должно получиться

Claude Code будет работать на твоём сервере и сможет помогать с задачами в пределах предоставленных разрешений. Ты отправишь ему первый запрос и увидишь результат.

Частые ошибки

  • Использовать устаревшие инструкции установки
  • Путать подписку Claude с API-оплатой
  • Давать ИИ доступ ко всему серверу без необходимости
