5. Telegram-бот для связи

Теперь твой ИИ буквально в кармане! Главное — не отправляй ему случайно список покупок вместо задания! 📱

Зачем это нужно

Необязательно каждый раз открывать терминал, чтобы обратиться к помощнику. Мы создадим Telegram-бота через официальный BotFather и подключим его к серверному приложению, которое передаёт сообщения Claude Code. Доступ ограничим твоим Telegram ID, а секретный токен сохраним отдельно от кода.

Как это устроено

Ты пишешь боту в Telegram → бот на сервере передаёт текст Claude Code → ответ возвращается в чат. Бот отвечает только тебе: чужие сообщения он молча игнорирует.

1. Создаём бота

  1. В Telegram найди официального бота @BotFather и отправь ему /newbot.
  2. Придумай название и имя бота (оканчивается на bot).
  3. BotFather пришлёт токен — длинную строку. Это пароль от бота: никому не показывай и не публикуй.

2. Готовим папку и окружение

mkdir -p ~/bot && cd ~/bot
sudo apt install -y python3-venv
python3 -m venv venv
./venv/bin/pip install python-telegram-bot

3. Файл с секретами

Токен хранится отдельно от кода, в файле .env. Сначала оставь OWNER_ID=0 — узнаем свой ID на следующем шаге.

nano ~/bot/.env
TELEGRAM_BOT_TOKEN=сюда_токен_от_BotFather
OWNER_ID=0
chmod 600 ~/bot/.env

4. Код бота

Создай файл ~/bot/bot.py и вставь в него код целиком:

nano ~/bot/bot.py
bot.py
import asyncio
import os
import shutil
from pathlib import Path

from telegram import Update
from telegram.ext import Application, CommandHandler, ContextTypes, MessageHandler, filters

TOKEN = os.environ["TELEGRAM_BOT_TOKEN"]
OWNER_ID = int(os.environ["OWNER_ID"])
WORKDIR = Path.home() / "workspace"
CLAUDE = os.environ.get("CLAUDE_BIN") or shutil.which("claude") or str(Path.home() / ".local/bin/claude")
WORKDIR.mkdir(exist_ok=True)


async def ask_claude(text: str, fresh: bool) -> str:
    cmd = [CLAUDE, "-p", "--allowedTools", "Read,Glob,Grep"]
    if not fresh:
        cmd.append("--continue")
    proc = await asyncio.create_subprocess_exec(
        *cmd, cwd=WORKDIR,
        stdin=asyncio.subprocess.PIPE, stdout=asyncio.subprocess.PIPE, stderr=asyncio.subprocess.PIPE,
    )
    try:
        out, err = await asyncio.wait_for(proc.communicate(text.encode()), timeout=600)
    except asyncio.TimeoutError:
        proc.kill()
        return "Слишком долго думаю, попробуй задачу попроще."
    if proc.returncode:
        return "Ошибка Claude Code:\n" + err.decode()[-500:]
    return out.decode().strip() or "(пустой ответ)"


async def cmd_id(update: Update, ctx: ContextTypes.DEFAULT_TYPE):
    await update.message.reply_text(f"Твой Telegram ID: {update.effective_user.id}")


async def cmd_new(update: Update, ctx: ContextTypes.DEFAULT_TYPE):
    if update.effective_user.id != OWNER_ID:
        return
    ctx.bot_data["fresh"] = True
    await update.message.reply_text("Начинаем новый разговор.")


async def on_text(update: Update, ctx: ContextTypes.DEFAULT_TYPE):
    if update.effective_user.id != OWNER_ID:
        return  # чужим не отвечаем вообще
    await update.message.chat.send_action("typing")
    answer = await ask_claude(update.message.text, ctx.bot_data.pop("fresh", False))
    for i in range(0, len(answer), 4000):
        await update.message.reply_text(answer[i:i + 4000])


if __name__ == "__main__":
    app = Application.builder().token(TOKEN).build()
    app.add_handler(CommandHandler("id", cmd_id))
    app.add_handler(CommandHandler("new", cmd_new))
    app.add_handler(MessageHandler(filters.TEXT & ~filters.COMMAND, on_text))
    app.run_polling()

Что делает код: команда /id показывает твой Telegram ID; любое обычное сообщение от владельца уходит в claude -p (режим «ответь и выйди»); по умолчанию Claude Code может только читать файлы (Read, Glob, Grep) — так безопасно начинать. Команда /new начинает новый разговор.

5. Узнаём свой ID и запускаем

cd ~/bot && set -a && . ./.env && set +a && ./venv/bin/python bot.py

Напиши боту в Telegram /id — он ответит числом. Останови бота (Ctrl+C), впиши число в .env вместо 0 и запусти снова. Теперь напиши боту любой вопрос — например, «что лежит в папке?».

Хочешь, чтобы бот мог ещё и создавать файлы и запускать команды? Добавляй нужные инструменты в --allowedTools по одному и только когда понимаешь, что они делают. Не выдавай боту разрешение на всё сразу.

Что должно получиться

Ты сможешь отправлять своему ИИ задания из Telegram и получать ответы прямо на телефон. Бот станет удобным интерфейсом для работы с сервером, а не открытым помощником для посторонних.

Частые ошибки

  • Публиковать токен Telegram-бота
  • Не ограничивать список разрешённых пользователей
  • Разрешать выполнение любых команд без проверки
