Как устроен наш сервер

Всё то же самое, что ты соберёшь по шагам, — только в большем масштабе! 🤖

На таком сервере у автора сайта круглосуточно работают Telegram-боты, связанные с Claude Code. Они помогают выполнять задачи, писать код и заниматься проектами, даже когда основной компьютер выключен. Автор управляет помощниками через Telegram и постепенно расширяет их возможности.

Из чего это состоит

  • Сервер на Ubuntu — обычный виртуальный сервер, который работает круглосуточно.
  • Несколько Telegram-ботов-помощников. Каждый — отдельная служба systemd со своей задачей: тексты, программирование, финансовая аналитика, работа с заказами. Один бот — одна папка и один набор правил.
  • Claude Code на сервере — «мозг» каждого помощника. Бот передаёт ему задачу и возвращает ответ в чат.
  • Удалённый доступ к сессиям — отдельная служба позволяет открывать рабочие сессии Claude Code с телефона.
  • Защита: вход по SSH-ключам, сетевой экран, fail2ban, секреты в отдельных файлах, а не в коде.
  • Рабочий стол и браузер на сервере — для задач, которые нужно делать через сайты. Это уже следующий уровень, он не нужен для старта.
Мы специально не показываем адреса, имена пользователей, токены и идентификаторы. На твоём сервере всё это будет твоим личным и закрытым.
